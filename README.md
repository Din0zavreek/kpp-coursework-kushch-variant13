Інформаційна система обліку та опрацювання технічних заявок готельного комплексу (Варіант №13)

Курсова робота з дисципліни «Кросплатформене програмування».  
Клієнт–серверна інформаційна система для автоматизації обліку номерного фонду готелю, реєстрації технічних заявок, розподілу завдань між спеціалістами, контролю чотиристанного життєвого циклу заявок (`НОВА → ПРИЗНАЧЕНА → В_РОБОТІ → ВИКОНАНО`), автоматичного розрахунку інтегрального показника пріоритету (I = 0.40 * F_1 + 0.35 * F_2 + 0.25 * F_3), фіксації записів виконання та фонового імпорту номерів із CSV-файлу.

1. Використані технології
Мова програмування: Java 21 (JDK 21)
Система збірки: Apache Maven[
Серверна частина: Java Servlet API 4.0.1 (`javax.servlet`), Apache Tomcat 9.x, JDBC, Jackson Databind 
База даних:** MySQL 8.x (кодування `utf8mb4`)
Клієнтська частина:** JavaFX 21 (`javafx-controls`), `java.net.http.HttpClient`
Тестування та журналювання:** JUnit 5 (`junit-jupiter`), `java.util.logging.Logger

3. Порядок підготовки бази даних MySQL
1) Запустіть сервер MySQL (через панель керування XAMPP або локальну службу).
2) Відкрийте phpMyAdmin (або клієнт командного рядка MySQL).
3) Виконайте SQL-скрипт database.sql з кореня проєкту. Він автоматично створить базу даних hotel_requests, чотири пов'язані таблиці (room, specialist, request, execution_record) та заповнить їх початковими демонстраційними записами.

4. Команди складання й запуску сервера
Перейдіть до каталогу серверного модуля та виконайте складання WAR-файлу за допомогою Maven:
cd server
mvn clean package
У каталозі server/target/ буде створено файл server-1.0-SNAPSHOT.war. Скопіюйте його до директорії webapps вашого Apache Tomcat 9.x та перейменуйте у server.war (щоб застосунок був доступний за базовою адресою http://localhost:8080/server)
Перевірте працездатність сервера, відкривши в браузері http://localhost:8080/server/rooms — сервер має повернути JSON-масив номерів

5. Порядок запуску JavaFX-клієнта
1) Переконайтеся, що MySQL та Apache Tomcat із розгорнутим сервером уже запущені.
2) Відкрийте термінал у каталозі client (запуск саме з цього каталогу необхідний для коректного пошуку файлу за відносним шляхом sample-data/rooms.csv) і виконайте:
   cd client
   mvn javafx:run
3) У вікні застосунку доступні чотири вкладки для керування даними: «Номери», «Спеціалісти», «Заявки» та «Виконання»

6. Команда запуску тестів JUnit 5
Модульні тести перевіряють обчислення інтегрального показника пріоритету, валідацію вхідних даних та допустимі/заборонені переходи станів заявки без необхідності підключення до MySQL чи запуску Tomcat. 
Для запуску тестів виконайте у каталозі
   cd server
   mvn clean test

7. Опис формату та використання CSV-файлу
Для масового додавання номерів готелю використовується фоновий імпорт (ImportRoomsTask на базі JavaFX Task<Integer> із відображенням прогресу через ProgressBar)
Кодування та роздільник: UTF-8, роздільник стовпців — крапка з комою (;)
Структура стовпців:
1) room_number (рядок, обов'язковий) — номер кімнати;
2) category (рядок, обов'язковий) — категорія номера (Стандарт, Напівлюкс, Люкс, Президентський тощо);
3) floor (ціле число > 0, обов'язковий) — поверх розташування.
Приклад вмісту файлу rooms.csv:
   room_number;category;floor
   103;Стандарт;1
   204;Напівлюкс;2
   301;Люкс;3
   305;Президентський;3
Використання: на вкладці «Номери» натисніть кнопку «Імпортувати CSV». 
Читання файлу та передавання записів через HttpHotelClient на сервер виконується у фоновому потоці без блокування інтерфейсу, а некоректні рядки фіксуються у журналі (Logger) та пропускаються
